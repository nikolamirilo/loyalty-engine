Loyalty Engine at a glance

In short
Loyalty Engine has two apps. Staff use the admin console to run the program. Members use the member app to see their points and prizes. Both open from the same start page.
Result
You know the two apps and where everything is.

1. The start page

The start page has three tiles. Continue as admin opens the admin console sign in. Continue as user opens the member app sign in. Read the documentation opens these docs. The two apps never share a session: signing in to one does not sign you in to the other.

2. The admin console

The console always shows one program at a time. The Program switcher at the top of the menu picks it. Every list in the console belongs to that program. Manage opens the Programs page.

3. The member app

Members sign in with their email and a code. The app shows the selected program's logo, name and colours . The four tabs are Home, Products, Wallet and Account. On a computer the app is drawn inside a phone frame.

Good to know

  • A person exists once, but has a separate membership in every program. Points, tier, segments, challenges, purchases and events belong to the membership.
  • Name, email and phone belong to the person. Changing them changes them in every program.
  • Every person is a member of every program. Creating a program adds everyone to it with 0 points.
  • A member has a different member ID in each program.

Set up your first program

In short
Create a program, give it a reward and a tier, then make orders earn points with an event and a rule. Finish by sending a test event and checking the result. It takes about fifteen minutes.
Result
A program with a reward, a tier and an event that earns points, tested on a member.
Before you start
  • The admin username and password

Part 1: Create the program

  1. Sign in to the admin console

    Go to /admin/login. See Sign in to the console.

  2. Open the Programs page

    Select Manage next to Program at the top of the menu, then New program.

  3. Enter a name

    For example "Daybreak Coffee". The program's short web name (its slug) is made from this name. Renaming the program in the console does not change it.

  4. Add a description

    Optional. It shows under the name on the Programs page.

  5. Upload a logo

    Optional. PNG, JPG, WebP or SVG, up to 2 MB.

  6. Pick a primary colour

    Optional. Buttons, links and highlights in both apps take this colour.

  7. Select Create program"Program created." Every existing member is added to it with 0 points.
  8. Switch to the new program

    Creating a program does not switch to it. Select Switch to on its row.

Part 2: Add a reward and a tier

  1. Open Rewards and select New reward
  2. Name it

    For example "Free espresso".

  3. Set the Points cost

    A whole number above 0, such as 150.

  4. Leave Stock blank

    Blank means unlimited.

  5. Keep Active ticked
  6. Select Create reward"Reward created."
  7. Open Tiers and select New tier

    Name it "Member", keep Rank 0 and Multiplier 1, add no conditions and select Create tier. With no conditions, every member qualifies, so everyone gets this tier. See Tiers.

Part 3: Make orders earn points

  1. Open Events and select New event
  2. Name it "Order placed"

    The API key under the name becomes orderPlaced. Your systems send this key.

  3. Add an attribute "Amount" of type Number

    Select Add attribute for each one.

  4. Select Create event"Event created. Add a rule, then turn it on." The event's page opens.
  5. Select New rule

    Name it "Points per euro". Leave IF empty. Under THEN, keep Earn points and change a fixed amount to the event's amount.

  6. Select Create rule"Rule created."
  7. Turn the event on

    New events start off. Use the switch next to Inactive at the top of the page. "Event turned on."

Part 4: Test it

  1. Add yourself as a member

    On Members, select New member and use your own email. See Members.

  2. Send a test event

    On the event's page, select Test event, pick your member, enter an Amount such as 12 and select Send test event."Event recorded. Earned 12 points."

  3. Check the member

    Open the member. Points balance shows 12, and Points activity lists "Effect of event Order placed".

  4. Check the member app

    Open /login, sign in with the same email and open Wallet.

Test events are real

A test event runs the rules for real. The member keeps the points, rewards and segments it gives, and it shows in the event log.

Members sign in to the default program

The member app always signs members in to the default program. If your new program is not the default, members switch to it on the Account tab. See Programs.

Give points for every order

In short
Let your till or online shop report each order, and give the member one point per euro they spend.
Result
Orders from your systems earn points automatically.

Steps

  1. Create the event

    On Events, select New event. Name it "Order placed" and add an attribute "Amount" of type Number. See Events.

  2. Add the rule

    On the event's page, select New rule. Leave IF empty. Under THEN, choose Earn points and pick the event's amount as the source. See Rules.

  3. Turn the event on

    Use the switch at the top of the event's page.

  4. Test it

    Select Test event and send one for a test member. See Test an event.

  5. Hand the request to your developers

    Copy the request from the Send this event card. Ask them to send the order number as eventId, so a resent order never earns twice. See Send events from your systems.

Good to know

  • The member's tier multiplier applies to earned points. A Gold member with ×1.5 earns 18 points for a 12 euro order.
  • Points are rounded to a whole number after the multiplier. Exact halves go to the even number (12.5 gives 12, 13.5 gives 14), and a result of 0 earns nothing.

Create a VIP tier

In short
Give hand-picked members a higher earn rate by putting them in a VIP segment and making a tier for that segment.
Result
VIP members earn at a higher rate.
Before you start
  • Some members to put in the VIP segment

Steps

  1. Create a segment called VIP

    On Segments, select New segment. See Segments.

  2. Add members to it

    On the VIP card, select Assign members, tick the members and select Assign.

  3. Create the tier

    On Tiers, select New tier. Name it "VIP", set Rank higher than your other tiers and Multiplier to 2.

  4. Add the condition

    Select Add condition, choose Segments, include, VIP.

  5. Select Create tier"Tier created." Every member is checked again at once, and the VIP members move to the new tier.

Give your lowest tier no conditions and rank 0. Every member who matches nothing higher lands there instead of having no tier.

Email a member a prize

In short
Give a member a free reward and email them a link to claim it.
Result
The member has a prize and an email to claim it.

Steps

  1. Open the member

    On Members, search for them and open their row.

  2. Select Redeem / assign

    At the bottom of the profile card.

  3. Tick "Email free prizes to the member, with a link to claim them"
  4. Select Assign free on the reward"Prize assigned and emailed."

Good to know

  • The member gets an email "You've won <reward>!" with a Claim your prize button. The link works for 30 days.
  • After 30 days, the member can still claim the prize in the member app, on Wallet.
  • A free prize costs no points but uses one unit of stock.
  • If the email fails, the prize stays assigned and the message says why.

See Rewards and prizes for a member and Emails members get.

Run a challenge for a segment

In short
Set a goal, such as five visits in May, for everyone in a segment, and pay points and a prize when they reach it.
Result
A segment works toward a goal and gets paid when they reach it.
Before you start
  • A segment with members in it
  • A reward to use as the prize

Steps

  1. Create the challenge

    On Challenges, select New challenge. Set Target to 5, Reward points to 200, pick a Prize reward and a deadline. See Challenges.

  2. Assign it to the segment

    On the challenge card, select Assign to segment, choose the segment and select Assign."Assigned to 58 member(s); 0 already had it."

  3. Count progress automatically

    On your "Order placed" event, add a rule with the effect Add challenge progress for this challenge. See Rules.

  4. Watch it

    Each member's page shows their progress under Challenges.

Good to know

  • People who join the segment later get the challenge automatically, while it is active and not expired.
  • If the segment is empty when you assign, nothing is recorded, so later joiners do not get it. Add members first.
  • Reaching the target completes the challenge and pays out at once.

Sign in to the console

Staff
In short
Sign in to the admin console with the staff username and password, and sign out when you are done.
Result
You are in the admin console, or safely signed out.
WhereStart page›Continue as admin
  1. Open the console

    On the start page, select Continue as admin, or go to /admin/login.

  2. Enter the Username
  3. Enter the Password
  4. Select Sign inThe Dashboard opens, showing the default program.

A wrong username or password shows a message with the attempts you have left.

Sign out

  1. Select Sign out

    At the bottom of the menu. On a phone, open the menu with first.You are back on the sign-in page. There is no confirmation.

Good to know

  • There is one staff account. Its username and password are set by whoever runs the server. There is no sign up, no password reset and no "remember me".
  • A session lasts 7 days from the moment you sign in. It does not get longer while you work. After 7 days, you sign in again.
  • After 3 wrong tries from the same network address, sign in is blocked for 10 minutes. While blocked, even the right password is refused.
  • Wrong tries do not need to be close together. They count until someone signs in from that address.
  • The counter is kept in the server's memory. It resets when the server restarts, and each server instance keeps its own count.
  • After signing in you always land on the Dashboard.
  • Signing out only ends the session in that browser.
  • Opening any console page while signed out takes you to the sign-in page.
Messages
What you seeWhat to do
"Invalid username or password. 2 attempts left before a 10-minute lockout."Check both fields. The message does not say which one is wrong.
"Too many failed attempts. Try again in 10 minutes."Wait. The minutes count down on each try.

The default program

One program is the default. It has the Default pill . The default program is the one:

  • the console shows after you sign in,
  • every member lands in after signing in to the member app,
  • your other systems write to when they do not say which program they mean.

To change it, edit another program and tick Use as the default program. The old default loses the pill in the same save.

  1. Copy program ID

    Copies the program's ID for your developers. "Program ID copied."

  2. Edit

    Opens the same fields. Select Save changes."Program updated."

  3. Delete

    Not shown on the default program. Read the warning below first.

Delete a program

Deleting a program removes everything inside it: memberships and points history, rewards and prizes, products and purchases, challenges, tiers, segments, events with their rules and history, member fields and the logo. People keep their accounts and their memberships in other programs. A window asks first, with Delete program. There is no undo. If you were viewing the deleted program, the console switches to the default one.

Good to know

  • Programs never share data. Rewards, tiers, segments and points in one program are invisible in another.
  • Creating a program adds every existing person to it with 0 points.
  • The program's slug (its short web name) is made from the name when you create it, such as daybreak-coffee. Renaming the program in the console does not change it. The Programs page does not show it.
  • The selected program is remembered until you close the browser or sign out, and applies to every console tab in that browser. Each sign in starts on the default program.
  • The program you are viewing shows "Currently viewing" on the Programs page.
  • If the name's slug is taken, a number is added, such as coffee-club-2.
  • If the logo fails while you edit a program, the other changes are already saved.
  • Programs are listed in the order they were created.

Example: the multiplier

Maya is Gold, with an earn rate of 1.5×. You earn 100 points for her. She gets 150. A Burn or Adjust of 100 changes her balance by exactly 100.

Good to know

  • A balance can never go below 0.

  • Tiers look at the current balance. Burning points can drop a member to a lower tier.
  • Points after the multiplier are rounded to a whole number. Halves round to the nearest even number. With a multiplier below 0.5, earning 1 point records 0.
  • Points are per program.

A member's challenges

In short
Give one member a challenge, record their progress, complete it for them, or take it away.
Result
The member's challenges are where they should be.
Where Members›a member›Challenges
Before you start
  • An active challenge. See Challenges
  1. Select Assign challenge

    Pick a challenge and select Assign."Challenge assigned."

  2. Select Progress to record progress

    Enter an Amount (default 1) and select Add progress."Progress recorded."

  3. Select Complete to finish it now"Challenge completed." Points and prize are paid at once.
  4. Select the bin to remove it

    Confirm with Remove."Challenge removed."

Good to know

  • Reaching the target completes the challenge on its own and pays out.
  • The payout is the challenge's reward points, plus its prize reward if that reward is active and in stock. Challenge points do not get the tier multiplier.
  • Complete pays out even if progress is short or the deadline has passed. It does not ask to confirm.
  • Removing a challenge keeps any points already paid. You can assign it again, and it starts from 0.
  • A member can have each challenge only once at a time.
  • A challenge past its deadline keeps its old status until progress is added, by you or by an event rule. Then it shows Expired.
  • Progress shows only for Assigned and In progress challenges. Complete also shows for Expired ones.
  • The Note in the Add progress window is not saved.
Messages
What you seeWhat to do

How several rules work together

  • Every active rule whose conditions all match runs. There is no "first match wins".
  • Conditions look at the member as they were when the event arrived, so one rule never changes whether another rule matches.

  • Rules run oldest first. There is no way to reorder them.
  • The tier is checked after every points change, and again after all rules ran. Earned points use the multiplier the member had when the event arrived.

Good to know

  • A skipped effect never stops the others. The log says why it was skipped.
  • "Only the first time per member" counts a run even when every effect was skipped, for example because the reward was out of stock. Editing the rule keeps this history.
  • Rule names can be up to 100 characters.
  • "is not" also matches when the attribute was not sent, or the member has no tier.
  • For text, "is" needs an exact match, including upper and lower case. "contains" ignores case.
  • Points from a rule show in Points activity as "Effect of event Order placed".

Verify an email address

  1. Select Verify my email in the email
  2. Select Verify my email on the page "Your email address is verified." The member can close the page.

Claim a prize from the email

  1. Select Claim your prize in the email
  2. Select Claim my prize on the page "Your prize is claimed."

Good to know

  • Neither page needs the member to be signed in.
  • Verification emails are sent by your own systems, not by the member app or the console. Members cannot ask for one in the app.
  • A new verification email replaces the old one, so older links stop working. Once the address is verified, any link shows success.
  • Verification counts in every program.
  • Prize emails are sent only when staff tick the email option while giving a prize. Prizes from rules and challenges send no email; they show in Wallet.
  • An expired prize link still lets the member claim the prize in Wallet. Signing in opens the default program, so the member may need to switch to the prize's program on Account first.
  • Claiming a prize twice is harmless.

Glossary

In short
Loyalty Engine words in plain language.
Result
Loyalty Engine terms in plain language.
API key
The short name of an event, such as orderPlaced, that your systems send.
Attribute
A piece of data sent with an event, such as the order amount.
Burn
Taking points away from a member. Shown as Spend in the history.
Challenge
A goal that pays points, a prize or both when the member reaches the target.
Custom attribute
A field your program adds to every member, such as a birthday.
Default program
The program members sign in to and that the console opens first.
Effect
One thing a rule does, such as Earn points.
Event
Something a member does that another system reports, such as placing an order.
Member
A person in a program. The same person is a member of every program, with separate points in each.
Multiplier
A tier's earn rate. 1.5 means 1.5 times the points.
Prize
A reward given for free, which the member can claim.
Program
A separate loyalty program with its own data, logo and colours.
Redemption
A reward a member got, either paid with points or given as a prize.
Rule
When an event happens, if conditions hold, then effects run.
Segment
A named group of members, such as VIP.
Slug
A program's short web name, such as daybreak-coffee. Renaming the program in the console does not change it.
Tier
A level, such as Gold, with conditions and a multiplier.
