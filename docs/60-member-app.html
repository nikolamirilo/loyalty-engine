Sign up and sign in

Members create an account and sign in with their email and a 6-digit code. There is no password.

{{i:map-pin}} WhereStart page›Continue as user
{{h:steps|Sign in}}
  1. Open the member app

    On the start page, select Continue as user, or go to /login.

  2. Keep Log in selected {{n:1}} and enter your Email {{n:2}}
  3. Select Send login code {{n:3}}"If ... has an account, we sent it a 6-digit code."
  4. Enter the Code from the email {{n:4}}

    The email's subject is "Your login code".

  5. Select Continue {{n:5}}The Home tab opens.
{{h:steps|Create an account}}
  1. Select Sign up
  2. Enter Name and Email

    Phone is optional.

  3. Select Create account

    Then enter the code and select Continue, as above. The screen then says "We sent a 6-digit code to ...".

{{h:steps|Get a new code}}
  1. Select Use a different email {{n:6}}

    There is no "resend" button. This takes you back to the first step with an empty form.

  2. Select Log in, enter the same email and select Send login code

    The form keeps the tab you were on, so check that Log in is selected. Wait at least 60 seconds after the last code.

{{h:rules|Good to know}}
  • A code works for 10 minutes and for 5 tries. Only the newest code works.
  • A new code can be sent once every 60 seconds, unless the last code was used to sign in. If you ask sooner, nothing is sent and you see no error. The code from a moment ago still works.
  • The app never tells you whether an email has an account. Log in with an unknown email sends nothing, and the screen looks the same. If no email arrives, check the address and try Sign up.
  • Sign up with an email that already has an account does not create a second account. It emails a login code for the existing account, and the name and phone you typed are ignored.
  • Signing in always opens the default program. Members switch program on the Account tab.
  • A member session lasts 30 days from sign in, or from the last program switch. Sign out with {{i:log-out}} at the top right. It takes you to the start page.
  • Sign up creates the account before the code is checked. If the email does not arrive, use Log in next time, not Sign up.
  • Signing in does not verify the email address. That is a separate email.
{{h:fix|Messages}}
What you seeWhat to do
"That code is invalid or has expired. Request a new one."Check the code in the newest email. If it still fails, the code may be wrong, expired, used up by 5 wrong tries, or already used. The same message also shows for an email with no account. Get a new code.
"Login code could not be sent - email delivery is misconfigured. ..."Trying again will not help. Tell whoever runs the server.
"Could not send the login code. Please try again shortly."Try again in a minute.

Open a campaign

The Home tab opens a campaign, such as a game, from a link. The campaign stays open while the member uses the other tabs.

{{i:map-pin}} Where{{i:house}} Home
{{h:steps|Open and close a campaign}}
  1. Paste the link into Campaign URL {{n:1}}

    The full link, including its start such as https://.

  2. Select Open campaign {{n:2}}

    Or press Enter.The campaign fills the screen between the header and the tabs.

  3. Reload it {{n:3}}

    Starts the campaign again from the beginning.

  4. Close it {{n:4}}

    The form comes back with the same link filled in.

{{h:rules|Good to know}}
  • The app adds the member's ID to the link as userId, so the campaign knows who is playing.
  • The campaign stays loaded while the member switches tabs. It keeps running in the background, sound included.
  • Switching program restarts an open campaign, with the member ID for the new program.
  • The browser remembers the link and whether it was open, also after sign out. Another member signing in on the same browser gets the same campaign.
  • Some sites refuse to open inside another app. They show the browser's own error.
{{h:fix|Messages}}
What you seeWhat to do
"Enter a campaign URL."Paste a link.
"Enter a valid campaign URL."Use the full link, including https://.

Products and purchases

The Products tab lists what the program sells, records purchases and shows what the member has spent.

{{i:map-pin}} Where{{i:shopping-bag}} Products
{{h:steps|Buy a product}}
  1. Open the Catalogue tab {{n:2}}

    Select a product to see its details.

  2. Select Buy {{n:3}}"Purchased for €14.50." The totals {{n:1}} and Purchase history update.
{{h:rules|Good to know}}
  • Buy records one unit at once. There is no confirmation, cart or undo.
  • No real payment happens and no points are earned. The spend counts toward tiers.
  • Spent (7d) covers the last 7 days up to now.
  • Purchase history shows the newest 200 purchases.
  • Only active products are listed. See Products.
  • Buying a product staff just removed shows "Product not found".
{{h:fix|Messages}}
What you seeWhat to do
"Product is not available"Staff turned the product off. Reload the page.
"Your session has expired. Please sign in again."Sign in again.

Wallet and prizes

The Wallet tab shows the member's points balance and the prizes they won, and lets them claim prizes.

{{i:map-pin}} Where{{i:wallet}} Wallet
{{h:steps|Claim a prize}}
  1. Find the prize under Prizes {{n:2}}
  2. Select Claim {{n:3}}"Prize claimed." The row shows Claimed.
{{h:rules|Good to know}}
  • The balance {{n:1}} is for the selected program only. It updates when the member opens Wallet or comes back to the app.
  • Prizes are rewards staff, rules or challenges gave for free. Rewards redeemed with points are not listed.
  • Members cannot spend points on rewards in the app. Staff do that on the member's page.
  • Claiming in Wallet works even after the email link has expired.
  • Balances of 10,000 and more are shortened, such as "12.9K".

Account and programs

The Account tab shows the member's tier and profile, lets them edit it, copy their member ID and switch to another program.

{{i:map-pin}} Where{{i:user}} Account
{{h:steps|Edit the profile}}
  1. Select the pencil {{n:3}}
  2. Change Name, Email or Phone

    Your sign-in code is sent to the email address.

  3. Select Save changes"Profile updated."
{{h:steps|Switch program}}
  1. Open Switch Loyalty Program {{n:4}}

    Only shown when there are two or more programs. Every program is listed. Picking one the member never used joins it with 0 points.

  2. Pick a program"Switched program." The whole app shows that program's logo, colours, points, tier, products and prizes.
{{h:rules|Good to know}}
  • The tier card {{n:1}} shows only when the member has a tier. The earn rate shows when it is above 1, such as "1.5x points".
  • A green tick next to the email means it is verified. The tick stays when the member changes the email, so it does not prove the new address.
  • Profile changes apply in every program.
  • A new email works for sign in at once, with no confirmation. A typo locks the member out, so check it.
  • Copy member ID {{n:2}} copies the ID for the current program: "User ID copied."
{{h:fix|Messages}}
What you seeWhat to do
"Email already registered"Another account uses that email.
"Something went wrong. Please try again."Try again, or sign out and in.
"You are not signed in."Sign in again.

Emails members get

Loyalty Simulator sends members three kinds of email: login codes, email verification (a link or a code) and prize claim links. The verification link and the prize link open a page in the member app.

{{h:opts|The emails}}
EmailSubjectWorks forOpens
Login code"Your login code"10 minutes, 5 triesNothing: type the code in the app
Email verification, link"Confirm your email address"10 minutes, 5 triesThe Verify your email page
Email verification, code"Your verification code"10 minutes, 5 triesNothing: the member types the code where they were asked
Prize"You've won <reward>!"30 daysThe claim page
{{h:steps|Verify an email address}}
  1. Select Verify my email in the email
  2. Select Verify my email on the page {{n:1}}"Your email address is verified." The member can close the page.
{{h:steps|Claim a prize from the email}}
  1. Select Claim your prize in the email
  2. Select Claim my prize on the page {{n:2}}"Your prize is claimed."
{{h:rules|Good to know}}
  • Neither page needs the member to be signed in.
  • Verification emails are sent by your own systems, not by the member app or the console. Members cannot ask for one in the app.
  • A new verification email replaces the old one, so older links stop working. Once the address is verified, any link shows success.
  • Verification counts in every program.
  • Prize emails are sent only when staff tick the email option while giving a prize. Prizes from rules and challenges send no email; they show in Wallet.
  • An expired prize link still lets the member claim the prize in Wallet. Signing in opens the default program, so the member may need to switch to the prize's program on Account first.
  • Claiming a prize twice is harmless.
{{h:fix|Messages}}
What you seeWhat to do
"This verification link is incomplete. Open the link from your email again, or request a new one."Open the link from the email again, without cutting it.
"Verification code has expired"Ask the company for a new verification email. Their system sends it.
"No active verification code for this member"The link was used up by 5 wrong tries. Ask for a new verification email.
"Invalid verification code"Use the newest email. Each wrong try uses one of 5 tries.
"This link has expired, but your prize is still waiting in your wallet."Select Sign in to claim it, switch to the prize's program on Account if needed, and claim it in Wallet.
"This prize link is not valid."The link was cut or changed, or the prize was deleted. Open the link from the email again. If it still fails, ask staff.
"This prize link is incomplete. Open the link from your email again."Open the full link from the email.
"You claimed this prize on Oct 21, 2026."Nothing to do. The prize is already claimed.
