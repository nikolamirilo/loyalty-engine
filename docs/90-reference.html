Troubleshooting

Find what you see, then follow the fix.

{{h:fix|Admin console}}
What you seeFix
Everything looks emptyCheck the program switcher at the top of the menu. You may be viewing another program.
The console opened on a different programThe selected program is forgotten when the browser closes, and every sign in starts on the default program. Switch back.
"Member not found" on a member linkThe link belongs to another program, or the member was deleted.
Grey placeholders that never go awayThat part did not load. Reload the page. If it stays, the server may be down.
"Cannot reach the API at ... Make sure the server is running."The loyalty server is down or unreachable. Contact whoever runs it.
"The API took too long to respond. Please try again."Try again in a moment.
"Database is temporarily unavailable. Please try again shortly."Wait a minute and try again.
"The request conflicts with existing data."Usually a reward that was already redeemed or given as a prize. Deactivate it instead of deleting it.
Edit or Delete in a reward's or product's {{i:ellipsis-vertical}} menu does nothingA known issue in the current version. Deactivate items you no longer want to offer.
"Something went wrong. Please try again."Try again. If it repeats, note what you did and contact support.
{{h:fix|Points, tiers and rules}}
What you seeFix
A member earned more points than you enteredTheir tier multiplier applied. See Earn, burn and adjust points.
A member dropped a tierTiers are checked again when the balance, purchases, segments or custom fields change. Spending points or leaving a segment can move a member down.
A member has no tierNo tier matched. Add a catch-all tier with no conditions.
An event earned nothingOpen Event logs. Check that the event and its rules are on, and that the conditions match.
Events from your systems are refusedThe event is off (new events start off), or your system sent a key or attribute the event does not have. See Events.
A "first time per member" rule does nothingIt already ran once for this member, even if its effects were skipped.
A challenge prize was not givenThe reward was inactive or out of stock when the challenge completed. Give it by hand on the member's page.
New segment members did not get a challengeThe challenge was assigned while the segment was empty, or it is inactive or expired. Assign it to the segment again.
{{h:fix|Member app}}
What you seeFix
A member cannot find their pointsThey may be in another program. They can switch on the Account tab.
The login code email never arrivedCheck spam. Select Use a different email, make sure Log in is selected, and request a new code after 60 seconds.
"That code is invalid or has expired. Request a new one."Check the code in the newest email, or request a new code.
A member mistyped their new email and cannot sign inOpen the member in the console, select Edit and fix the email.

Glossary

Loyalty Engine words in plain language.

{{o:API key}}The short name of an event, such as orderPlaced, that your systems send.{{/o}} {{o:Attribute}}A piece of data sent with an event, such as the order amount.{{/o}} {{o:Burn}}Taking points away from a member. Shown as Spend in the history.{{/o}} {{o:Challenge}}A goal that pays points, a prize or both when the member reaches the target.{{/o}} {{o:Custom attribute}}A field your program adds to every member, such as a birthday.{{/o}} {{o:Default program}}The program members sign in to and that the console opens first.{{/o}} {{o:Effect}}One thing a rule does, such as Earn points.{{/o}} {{o:Event}}Something a member does that another system reports, such as placing an order.{{/o}} {{o:Member}}A person in a program. The same person is a member of every program, with separate points in each.{{/o}} {{o:Multiplier}}A tier's earn rate. 1.5 means 1.5 times the points.{{/o}} {{o:Prize}}A reward given for free, which the member can claim.{{/o}} {{o:Program}}A separate loyalty program with its own data, logo and colours.{{/o}} {{o:Redemption}}A reward a member got, either paid with points or given as a prize.{{/o}} {{o:Rule}}When an event happens, if conditions hold, then effects run.{{/o}} {{o:Segment}}A named group of members, such as VIP.{{/o}} {{o:Slug}}A program's short web name, such as daybreak-coffee. Renaming the program in the console does not change it.{{/o}} {{o:Tier}}A level, such as Gold, with conditions and a multiplier.{{/o}}
