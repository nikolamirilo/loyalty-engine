Acme documentation

{{i:folder-kanban}}Plan projects

Find what you see and follow the fix.

Create your first project

Create a project, add a task and share it with a teammate. It takes about five minutes.

{{h:steps|Part 1: Create the project}}
  1. Select New project

    At the top right of the project list.

  2. Enter a name

    Up to 80 characters. You can change it later.

  3. Choose who can see it

    Private is the default. Only people you add can open the project.

  4. Select CreateThe new project opens on its Tasks tab.
{{h:steps|Part 2: Share it}}
  1. Open the Members tab

    In project settings.

  2. Select Add member and enter an emailYour teammate gets an email with a link to the project.
[[tip Tip]]

Give each project a name your team will recognize in search, such as "Website relaunch 2026".

[[/]] [[warn Members see everything in the project]]

Anyone you add can see every task and file in it. Use a separate project for private work.

[[/]]
