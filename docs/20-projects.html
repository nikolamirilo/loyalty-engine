Projects

A project holds the tasks, files and people for one piece of work.

{{i:map-pin}} Where{{i:folder-kanban}} Projects
{{h:steps|Find a project}}
  1. Search by name {{n:2}}

    Type at least 2 letters. The list filters as you type.

  2. Open it

    Select its row {{n:3}}.

{{h:opts|Project fields}}
{{o:Name|req;lim=Max 80 characters}}Shown in the list and in search. Two projects can have the same name.{{/o}} {{o:Visibility|def=Private}}
PrivateWorkspace
Private: only members. Workspace: everyone in your workspace can view it.{{/o}} {{o:Due date|opt}}The day the work should be done. Shown in red after it passes.{{/o}}
{{h:rules|Good to know}}
  • Archived projects are read only. Restore one to change it.
  • Only owners can delete a project.

{{h:risk|Delete a project}}

Deleting removes every task and file in the project for everyone. It cannot be undone. Archive the project instead if you might need it later.

{{h:fix|Messages}}
"Name is required"Enter a name.
"Name is too long"Use 80 characters or fewer.
